# ivylink
ivylink is a minimal declarative dotfile manager — it handles symlinks, 
theme switching with templates, and systemd services all from a single KDL 
config file and a one lightweight binary.

## Why ivylink?
First and foremost, I want to learn Rust, and tools like home-manager and 
GNU Stow get *close* but not quite there for me. I enjoy writing my own 
tooling and owning my stack.

## Config
ivylink is configured via `config.kdl`. See `template.kdl` for a full example.
